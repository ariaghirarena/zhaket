# صفحهٔ محصول ژاکت — بچرخون

همهٔ چیزهایی که برای ثبت محصول «بچرخون» در ژاکت لازم داری.

## از کجا شروع کنم؟

**→ `بستهٔ آپلود ژاکت/`**

داخلش سه چیز هست:

| مسیر | چیست |
|---|---|
| `becharkhoon-zhaket-package.zip` | فایل محصول برای آپلود در فرم ثبت ژاکت (۵.۷ مگابایت) |
| `graphics/` | آیکون ۸۰ و ۵۱۲، دو کاور ۷۰۰، کاور ۴۰۰، شش تکهٔ بنر ۱۲۴۰ |
| `README.md` | راهنمای گام‌به‌گام + بررسی‌های انجام‌شده |
| `listing-becharkhoon.md` | همهٔ فیلدهای فرم، آمادهٔ کپی |
| `listing-becharkhoon.pdf` | همان فایل، برای خواندن راحت‌تر |
| `description-zhaket.html` | متن توضیحات کامل با بنرها |

## ترتیب کار

۱. `listing-becharkhoon.md` را بخوان.
۲. بنرها را روی هاست خودت آپلود کن و آدرسشان را در `description-zhaket.html` بگذار.
۳. محصول را در پنل فروشندهٔ ژاکت بساز، فیلدها را از فایل لیستینگ پر کن.
۴. `becharkhoon-zhaket-package.zip` را در بخش فایل محصول آپلود کن.
۵. تصاویر `graphics/` را در گالری و آیکون بگذار.
۶. متن توضیحات را در حالت HTML پیست کن.

## فایل‌های سورس (برای بازسازی)

| فایل | چه کاری می‌کند |
|---|---|
| `mkbanner.js` | شش تکهٔ بنر ۱۲۴۰×۸۰۰ را می‌سازد |
| `mkdesc.py` | متن توضیحات HTML را می‌سازد |
| `mklisting.py` | فایل لیستینگ markdown را می‌سازد |
