# بستهٔ ثبت محصول بچرخون در ژاکت

دو چیز جدا در این پوشه هست:

## ۱. `becharkhoon-zhaket-package.zip` — بستهٔ فایل محصول

این همان فایلی است که در فرم ثبت محصول آپلود می‌کنی.

```
becharkhoon/
├── 1- Plugin/
│   └── becharkhoon.zip              ← زیپ خود افزونه (تک‌ریشه: ariagh-becharkhoon/)
├── 2- Addons/
│   └── Zhaket-Smart-Updater.zip     ← آپدیتر رسمی ژاکت (تک‌ریشه: zhaket-updater/)
├── 3- Documentation/
│   └── becharkhoon-guide.html       ← راهنمای فارسی آفلاین، بدون لینک بیرونی
├── Help.pdf                          ← راهنمای نصب و بروزرسانی، ۸ صفحه
└── description-zhaket.html           ← متن توضیحات محصول (برای کپی‌پیست)
```

**نکتهٔ مهم:** فایل `description-zhaket.html` داخل خود زیپ محصول لازم نیست —
فقط برای راحتی تو گذاشته شده. اگر حجم زیپ برایت مهم است، می‌توانی حذفش کنی.

## ۳. `description-zhaket.html` و `listing-becharkhoon.md`

- `listing-becharkhoon.md` — همهٔ فیلدهای فرم ثبت، آمادهٔ کپی. **اول این را بخوان.**
- `description-zhaket.html` — متن توضیحات کامل با بنرها.

### قبل از پیست کردن توضیحات

تصاویر بنر باید روی یک آدرس عمومی باشند. آن‌ها را در هاست خودت آپلود کن
(مثلاً در `public_html/zhaket/`) و این شش خط را در فایل HTML جایگزین کن:

| در فایل | جایش بگذار |
|---|---|
| `banner-p6-01.jpg` | `https://دامنه-تو/zhaket/banner-p6-01.jpg` |
| `banner-p6-02.jpg` | `https://دامنه-تو/zhaket/banner-p6-02.jpg` |
| … | … |

بعد کل فایل را در حالت **متن/HTML** ویرایشگر توضیحات ژاکت پیست کن
(نه در حالت بصری، وگرنه تگ‌ها به‌هم می‌ریزند).
