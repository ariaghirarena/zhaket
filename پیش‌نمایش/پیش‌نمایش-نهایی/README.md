# پیش‌نمایش بچرخون — بستهٔ آمادهٔ آپلود روی cPanel

## ۱. نصب در سه قدم

1. فایل `becharkhoon-preview.zip` را در **public_html** آپلود کن.
2. روی فایل، **Extract** بزن (گزینهٔ «Extract Files» یا «Unarchive» در فایل‌منیجر).
3. آدرس دامنه را باز کن. اگر می‌خواهی در زیرپوشه باشد، پوشهٔ `becharkhoon-preview` را نگه دار؛
   اگر می‌خواهی روی ریشه باشد، **محتوای** پوشه را به `public_html` منتقل کن (نه خودِ پوشه).

> اگر هاست فایل `.htaccess` را مخفی می‌کند: در File Manager → Settings → «Show Hidden Files (dotfiles)» را روشن کن.

## ۲. ساختار

```
becharkhoon-preview/
├── index.html            ← صفحهٔ معرفی (۱۴ بخش)
├── site.css / site.js
├── .htaccess             ← UTF-8، جلوگیری از فهرست پوشه، mime فونت، فشرده‌سازی
├── assets/fonts/         ← Morabba (Black, Medium) + Peyda (Medium, Bold, Black)
└── demo/                 ← دموی واقعی پنل (رابط خود افزونه)
    ├── index.html        ← پوسته + ترتیب بارگذاری
    ├── mock-api.js       ← پاسخ همهٔ مسیرهای REST از دادهٔ نمونه
    ├── demo.css          ← فونت محلی + نوار هشدار دمو
    ├── README.md         ← توضیح روش ساخت و نگهداری
    ├── plugin/assets/    ← کپی بایت‌به‌بایت از CSS/JS افزونه ۱.۸.۰
    └── vendor/font/      ← Vazirmatn (همان فونت رسمی پنل)
```

## ۳. چه چیزی داخلش هست

- **دموی پنل:** رابط واقعی افزونه (app.css + ۷ فایل JS خود افزونه) با لایهٔ
  دادهٔ نمونه در مرورگر؛ ۱۴ نمای پنل شامل داشبورد، گردونه‌ها، ادیتور گردونه با
  پیش‌نمایش زندهٔ چرخ، قوانین، چرخش‌ها، مخاطبان، شانس‌ها، ارسال گروهی، گزارش‌ها،
  پیامک، تنظیمات، ابزارها و راهنما. هیچ وردپرس/دیتابیسی اجرا نمی‌شود و
  عملیات نوشتن با پیام صریح رد می‌شود.
- **صفحهٔ معرفی:** هیرو با گردونهٔ SVG، آمار (۵۰۰ / ۳۶ / ۱۲ / ۵۱ / ۲۶)، سه حالت دسترسی،
  ۱۱ رویداد کسب شانس، بنتوی قابلیت‌ها، ۱۴ نوع جایزه، ۵۱ شرط در ۵ ستون، ۳۶ تم با پالت واقعی،
  پیامک و شبیه‌ساز موبایل، گزارش مالی، گالری ۱۲ صفحهٔ پنل، ۱۲ الگو، پرسش‌های متداول و فوتر.

## ۵. تست‌های انجام‌شده

- توازن تگ‌ها در `index.html` و `demo/index.html` — سالم.
- `node --check` روی `site.js` و `demo/mock-api.js` — بدون خطا.
- درخواست‌های HTTP محلی برای صفحهٔ معرفی، استایل، فونت‌ها و همهٔ دارایی‌های پنل — همه ۲۰۰.
- **بارگذاری واقعی پنل در DOM بدون مرورگر:** هر ۱۴ نما (داشبورد، گردونه‌ها، ادیتور،
  قوانین، چرخش‌ها، مخاطبان، شانس‌ها، ارسال گروهی، گزارش کامل کمپین، گزارش‌ها، پیامک،
  تنظیمات، ابزارها، راهنما) بدون هیچ خطای جاوااسکریپت و بدون هشدار خطا رندر شد.
- **تست رفتار:** عملیات نوشتن → ۴۰۳ با پیام صریح؛ مسیر ناشناخته → لیست خالی؛
  ساخت گردونه از الگو → همان پیام رد، مودال باز می‌ماند (موفقیت جعلی نداریم).
- **تست موبایل:** دکمهٔ منو و کشوی ناوبری روی ۳۹۰ پیکسل کار می‌کند (کد خود افزونه)،
  روی ۱۴۴۰ هم بدون خطا.
- گرِپ `http://` و `https://` در HTML/CSS/JS — صفر درخواست بیرونی.

## ۶. اگر خواستی تغییر بدهی

- رنگ‌ها: متغیرهای `:root` بالای `site.css` (پالت سبز جنگلی/نارنجی/طلایی) و `demo.css` (آبی برند پنل).
- متن‌های صفحهٔ معرفی: مستقیم در `index.html` (هر بخش با کامنت شماره‌گذاری شده).
- داده‌های دمو: `demo/mock-api.js` (همهٔ پاسخ‌ها و داده‌های نمونه).
