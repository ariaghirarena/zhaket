# دموی پنل بچرخون — چطور ساخته شده

این پوشه **دموی واقعی پنل** است: همان CSS و همان جاوااسکریپت افزونهٔ
«بچرخون» نسخهٔ ۱.۸.۰، بدون هیچ تغییری. تنها چیزی که اضافه شده، لایهٔ دادهٔ
سمت مرورگر است تا پنل بدون وردپرس بالا بیاید.

## ساختار

```
demo/
├── index.html          ← پوستهٔ صفحه + ترتیب بارگذاری
├── themes-data.js      ← ۳۶ تم واقعی (کپی assets/data/themes.json)
├── mock-api.js         ← رهگیر fetch؛ پاسخ همهٔ مسیرهای REST
├── demo.css            ← فونت محلی + نوار هشدار دمو (تنها استایل اضافه)
├── plugin/             ← کپی بایت‌به‌بایت از خودِ افزونه
│   ├── assets/admin/   app.css, ui.js, charts.js, fields.js, editor.js, pages.js, app.js
│   ├── assets/front/   wheel.css, wheel.js
│   └── assets/img/     mark.svg, logo.svg, logo-white.svg, menu-icon.svg
└── vendor/font/        Vazirmatn (woff2، همان فونت رسمی افزونه)
```

## چرا این روش؟

ساخت دمو به این شکل یعنی هر چیدمان، هر رنگ و هر رفتار تعاملی که می‌بینی،
خروجی مستقیم کد خود افزونه است؛ اگر فردا نسخهٔ ۱.۸.۱ بیاید، فقط فایل‌های
`plugin/` را جایگزین می‌کنیم و دمو همان روز به‌روز می‌شود.

## چه چیزی واقعی است و چه چیزی نیست

| بخش | وضعیت |
|---|---|
| رابط، استایل، فونت، آیکون‌ها، نمودارها، ادیتور گردونه | **واقعی** — کد خود افزونه |
| داده‌ها (چرخش‌ها، مخاطبان، گزارش‌ها، تنظیمات) | نمونه |
| پیش‌نمایش گردونه در کارت‌ها و ادیتور | **واقعی** — موتور `wheel.js` خود افزونه |
| ۳۶ تم و اعمال تم | **واقعی** — `themes.json` اصلی + `apply_theme` |
| ذخیره‌سازی، دیتابیس، ارسال پیامک، ووکامرس | وجود ندارد |

هر درخواست `POST/PUT/DELETE` با کد ۴۰۳ و پیام
«این عمل در دموی مرورگری غیرفعال است؛ روی سایت واقعی اجرا می‌شود.» رد می‌شود؛
هیچ‌جا موفقیت جعلی نشان داده نمی‌شود.

## اجرا

مرورگرها `fetch` را روی `file://` محدود می‌کنند. پس دمو را با یک سرور ساده ببین:

```bash
cd demo
python3 -m http.server 8080
# یا فقط کل پوشهٔ پیش‌نمایش را روی هر هاست/سی‌پنلی آپلود کن
```

## نگهداری

1. فایل‌های `plugin/assets/**` را **هرگز** دستکاری نکن؛ فقط از زیپ رسمی افزونه کپی کن.
2. اگر مسیر REST جدیدی اضافه شد، فقط در `mock-api.js` یک handler اضافه کن.
   اگر تم‌ها تغییر کرد، `themes-data.js` را از `assets/data/themes.json` دوباره کپی کن
   (mock با `applyTheme()` همان کاری را می‌کند که `Templates::apply_theme()` در PHP).
3. شکل پاسخ هر handler باید با خروجی واقعی همان endpoint یکی باشد
   (`src/Admin/Rest.php`، `Stats.php`، `Settings.php`).
4. کلیدهای پیش‌فرض گردونه در `CONFIG_DEFAULTS` از `src/Wheels/Schema.php`
   استخراج شده‌اند؛ با تغییر اسکیمای افزونه، همین آبجکت را دوباره بساز.
