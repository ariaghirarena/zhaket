## چه چیزی تحویل داده می‌شود

1. **صفحهٔ معرفی** با یک هیرو موشن‌دار تمام‌صفحه در ابتدا، و بعد ۱۴ بخش توضیحی:
   گردونهٔ SVG زنده و همهٔ اعداد واقعی افزونه — ۵۰۰ قابلیت، ۳۶ تم، ۱۲ الگو، ۵۱ شرط،
   ۲۶ پنل پیامک، ۱۴ نوع جایزه.
   - **هیرو:** چهار جایزه (جایزه / شانس / لبخند / جشن)، هر کدام یک رنگ کامل و یک
     گردونهٔ واقعی از تم همان رنگ؛ واژهٔ غول‌آسا پشت گردونه، تکه‌های شناور با عمق،
     پردهٔ اندازه‌گیری‌شده با پارالاکس، تب‌های زیرخط‌دار، پخش خودکار، سوایپ، کلیدها و
     توالی ورود. با `prefers-reduced-motion` و بدون JS هم سالم دیده می‌شود.
   - **موشن ادامهٔ صفحه:** باکس‌ها، کارت‌ها، سطرها، عکس‌ها و عنوان‌ها با اسکرول
     وارد می‌شوند؛ اعداد آمار شمرده می‌شوند؛ نوار پیشرفت اسکرول بالای صفحه است.
2. **دموی تعاملی پنل** با ۱۲ صفحه و مسیریابی hash — بدون reload، بدون سرور.
3. **فونت‌های فارسی** (Morabba Black/Medium + Peyda Medium/Bold/Black) همراه بسته،
   بنابراین روی هر هاستی بدون اینترنت بیرونی همان‌طور دیده می‌شود.
