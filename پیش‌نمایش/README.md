## چه چیزی تحویل داده می‌شود

1. **صفحهٔ معرفی استاتیک** (۱۴ بخش) با گردونهٔ SVG زنده و همهٔ اعداد واقعی افزونه:
   ۵۰۰ قابلیت، ۳۶ تم، ۱۲ الگو، ۵۱ شرط، ۲۶ پنل پیامک، ۱۴ نوع جایزه.
2. **دموی تعاملی پنل** با ۱۲ صفحه و مسیریابی hash — بدون reload، بدون سرور.
3. **فونت‌های فارسی** (Morabba Black/Medium + Peyda Medium/Bold/Black) همراه بسته،
   بنابراین روی هر هاستی بدون اینترنت بیرونی همان‌طور دیده می‌شود.
