# اسکیل ساخت پیش‌نمایش — بچرخون (Becharkhoon)

> این فایل «دستور پخت» کامل پیش‌نمایش است: پالت، فونت، ساختار، اعداد، و روش‌های تست.
> کیفی که اینجا تعریف می‌شود باید **دقیقاً** همان کیفی باشد که تحویل داده می‌شود.

---

## ۱. هدف و قواعد ثابت

- پیش‌نمایش = یک سایت استاتیک **فارسی/RTL** که روی cPanel با `public_html` کار کند (بدون PHP).
- **همان نسخهٔ افزونه**؛ عدد هیچ نسخه‌ای در متن/تصویر نیاید.
- **صفر لینک بیرونی** (حتی دامنهٔ خود فروشنده). همه‌چیز نسبی و محلی.
- دموی پنل باید **تعاملی** باشد (۱۲ صفحه، بدون reload، با دادهٔ نمونه)؛ نه عکس.
- گردونه باید **SVG واقعی** با انیمیشن چرخش باشد، نه تصویر.

## ۲. پالت (منبع: پرامپت رسمی محصول)

```css
--forest-mid:#2A5125; --forest-deep:#1E381B;
--orange:#E47C12; --orange-d:#C4640A;
--emerald:#2FA463; --spin-green:#3CC47E;
--gold:#FFC517; --gold-d:#E0A800;
--cream:#F2F0E6; --ink:#17281A; --muted:#93A98C;
--turq:#4BC2D6; --pink:#E9A8E0;
```
گرادیان زمینه:
`radial-gradient(900px 520px at 78% -8%, #3A6B32 0%, transparent 62%), radial-gradient(700px 420px at 6% 108%, #1B3418 0%, transparent 60%), linear-gradient(165deg,#2A5125 0%,#24461F 55%,#1E381B 100%)`
بافت گراف‌پیپر ۲۴px با `rgba(242,240,230,.035)` + نویز فیلم ۰٫۰۳.

## ۴. گرید و ابعاد

| مورد | مقدار |

| گاتر گرید | ۲۴px |

## ۵. ۱۴ بلوک صفحه (به ترتیب)

1. **تاپ‌بار** شیشه‌ای: لوگو (`mark` + وردمارک) · منو · دکمهٔ «دموی زنده».
2. **هیرو:** H1 سه‌خطی با کلمهٔ طلایی، لید ۲ خط، ۴ چیپ، ۲ دکمه، آرت سه‌بعدی گردونه در قاب شیشه‌ای، ۳ پیل شناور (`۵۰۰ قابلیت / ۳۶ تم / ۲۶ پنل`).
3. **نوار آمار:** ۵۰۰ · ۳۶ · ۲۶ · ۱۲ · ۱۴ (با Morabba 42px).
4. **سه حالت دسترسی:** کارت با نمودار ساده و برچسب «آزاد / با شانس / ترکیبی».
5. **۱۱ قانون کسب شانس:** شبکهٔ ۳×۴ چیپ با آیکون.
6. **بنتوی قابلیت‌ها:** ۱۰ کارت (۳ ستون، کارت اول ۲ ستون).
7. **۱۴ نوع جایزه:** چیپ دوستونه با آیکون و توضیح یک‌خطی.
8. **۵۱ شرط:** ۵ ستون گروهی + شمارنده روی هر ستون.
9. **۳۶ تم:** گرید ۱۲×۳ نمونهٔ رنگی از `themes-36.json` (هر نمونه یک گردونهٔ کوچک SVG با همان پالت).
10. **پیامک:** ۲۶ پنل در چیپ + بلوک «متن یا پترن» + شبیه‌ساز موبایل.
11. **گزارش‌ها:** کارت با ۴ عدد پول واقعی + اسکرین‌شات.
12. **گالری:** ۱۲ اسکرین‌شات با کپشن.
13. **۱۲ الگو:** کارت سناریو.
14. **پرسش متداول + فوتر** (لوگوی ژاکت در چیپ سفید، وسط‌چین، بدون متن کنارش).

## ۶. دموی پنل (`demo/`)

- ۱۲ صفحه: `dashboard, wheels, rules, spins, leads, credits, campaigns, reports, sms, settings, tools, guide`
- SPA با hash routing، سایدبار تیرهٔ `#0B1B3F` (رنگ برند پنل)، محتوای روشن.
- جدول‌ها با ۵–۸ ردیف دادهٔ فارسی نمونه (نام، موبایل `0912…`، جایزه، تاریخ شمسی).
- نمودارها با CSS/Canvas ساده (بدون کتابخانه).
- نوار «داده‌های نمونه — دمو» بالای محتوا (مجاز).
- هیچ فرم لایسنس، هیچ لینک بیرونی، هیچ عدد نسخه.

## ۷. روش ساخت و تست

```bash
# ۱) سرو محلی برای تست
python3 -m http.server 8080 -d پیش‌نمایش/پیش‌نمایش-نهایی

# ۲) اسکرین‌شات ۱۴۴۰×۹۸۰ با Playwright (در صورت دسترسی)
#    viewport 1440×980، DPR=2، بعد از هر صفحه بررسی Fatal/Warning

# ۳) بررسی صفر درخواست بیرونی
grep -rn "http://\|https://" --include=*.html --include=*.css --include=*.js .

# ۴) بررسی فونت‌ها
grep -rho "url([^)]*)" --include=*.css . | sort -u   # هر url() باید فایل موجود باشد
```

## ۸. بسته‌بندی نهایی

```
becharkhoon-preview/        ← یک ریشهٔ واحد
becharkhoon-preview.zip     ← همین را در public_html اکسترکت کن
```
هیچ پوشهٔ اضافه، هیچ `.DS_Store`، هیچ فایل کاری (working copy) در بسته نباشد.

```

[ ] ۴ عدد کلیدی از JSON تطبیق داده شده: ۳۶ / ۱۲ / ۵۱ / ۲۶ / ۱۴ / ۵۰۰
[ ] موبایل ۳۹۰ و تبلت ۷۶۸ بدون اسکرول افقی
[ ] همهٔ لینک‌های داخلی ۲۰۰
[ ] حجم صفحهٔ اول < ۱.۵MB و کل بسته < ۸MB

```
