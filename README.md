# ژاکت — پروژه‌های افزونه (AriaGhasemi)

> هر پروژه در پوشهٔ خودش، با ساختار یکسان: **دانش → تست → پیش‌نمایش**.
> ریشهٔ مخزن تمیز نگه داشته می‌شود؛ هیچ فایل کاری بیرون از پوشه‌ها نمی‌ماند.

---

## ۱. نقشهٔ ریشه

| مسیر | چیست |
|---|---|
| `صفر تا صد اطلاعات کسب‌شده از افزونه/` | دانشنامهٔ «بچرخون»: بکاپ‌های خام، مستندات، داده‌های استخراج‌شدهٔ JSON، ۷ سند تحلیلی |
| `کار های تستی/` | مادرِ کارهای تستی — `تست کاور ها/کاور 700x700/` و `تست پیش‌نمایش/` |
| `پیش‌نمایش/` | بستهٔ نهایی آپلود cPanel + اسکیل ساخت + نسخهٔ کاری |
| `ARIAGH-*.zip` | بسته‌های محصول (منبع خام) |

| ۳ | `صفر تا صد اطلاعات کسب‌شده از افزونه/` | دانشنامهٔ کامل: هر عدد از کد شمرده شده، نه از حافظه. |

## ۴. هفت قانون ثابت

1. **اول اسپک را بخوان، بعد بساز.**
2. **چیزی که کاربر نگفته اضافه نکن**؛ اگر ایده داری، بپرس.
3. **هیچ عدد نسخه و کلمهٔ «نسخه»** در کاور، اینفوگرافیک، دمو و راهنما.
4. **صفر لینک بیرونی** در توضیحات، راهنما و پیش‌نمایش.
5. **دمو همان نسخهٔ ارسالی** و روی دامنهٔ خود فروشنده.
6. **فایل تحویلی را نام ببر**؛ فایل کاری را کنار بگذار و برچسب بزن.
7. **راستی‌آزمایی با عدد:** هر ادعا باید از کد یا فایل شمرده شود.
