## چرا این‌طور ساخته شد؟

- کل تصویر **یک SVG برداری** است؛ در نتیجه در هر مقیاسی بدون پیکسل‌شدن رندر می‌شود. هر دکمه همان SVG را در یک canvas می‌کشد و PNG می‌دهد ⇒ **آن‌چه می‌بینی = آن‌چه خارج می‌شود**.
