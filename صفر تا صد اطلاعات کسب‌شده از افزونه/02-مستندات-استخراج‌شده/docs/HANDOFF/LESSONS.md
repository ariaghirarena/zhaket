## ب) اشتباهات توسعه/تست (تکرار نکن)

1. **`done()` در `tests/test-engine.php` با exit تمام می‌شود** → تست جدید باید قبل از آن اضافه شود (تست‌های بعد از آن هرگز اجرا نمی‌شوند و «همه پاس» دروغ است).
2. `use` تکراری در فایل تست (Guard در بالا import شده) → Fatal. قبل از اضافه کردن `use` بالای فایل را grep کن.
3. تست placeholder مثل `... || true` نگذار؛ assertion واقعی بنویس.
4. کلید نتیجه چرخش `slice_id` است نه `slice`.
5. `Helpers::lines()` روی کاما هم جدا می‌کند → برای «شماره، نام» split اختصاصی.
6. `switch` در PHP مقایسه شل دارد (`'+98' == '98'`) → زنجیره if با `===`.
7. زمان در تست‌ها: از `Helpers::now()` استفاده کن (قابل جابه‌جایی)، نه `time()` مستقیم در کوئری.
8. stub دیتابیس SQLite متد `replace()` نداشت → `INSERT OR REPLACE`. stubها کامل نیستند؛ اگر تابع وردپرس جدید استفاده شد، stub آن را در `wp-stubs.php` یا با `function_exists` در تست اضافه کن.
9. متد private مورد نیاز کلاس دیگر (`Ledger::t`) → public کن، نه کپی SQL.
10. devserver می‌میرد اگر با `&` ساده اجرا شود → `setsid nohup … & disown`.
11. پارامتر باز کردن در devserver `bch-open` است، پیش‌فرض واقعی `bch_open` (`Settings open_param`).
12. `do_shortcode` در stub متن خام برمی‌گرداند → برای تست inline از `?sc=ID` در devserver (که `Shortcodes::wheel` را صدا می‌زند).
13. Playwright: اسکرول لمسی با `Input.dispatchTouchEvent`، نه `synthesizeScrollGesture`.
14. فرم ادمین: با `fill()` روی input عددی، مقدار مدل را از بدنه درخواست شبکه چک کن (باگ ۳ فقط این‌طور پیدا شد).
15. هنگام جایگزینی متن با اسکریپت پایتون، تورفتگی (tab) دقیق را با `cat -A` ببین؛ assert بگذار تا جایگزینی بی‌صدا شکست نخورد.
16. FEATURES.md باید دقیقاً ۵۰۰ بماند: آیتم اضافه نکن؛ آیتم‌های هم‌خانواده را ادغام کن و مراقب باش آیتم واقعی (مثل فونت) پاک نشود.
17. ویژگی جدید سمت سرور = REST route در `Rest::routes` + متد + stub در devserver (router devserver regex مسیرها را پشتیبانی می‌کند).

## ج) محیط و ابزار

1. sandbox ابری Claude به pypi/github/npm/crates دسترسی ندارد → نصب ابزار فقط روی کامپیوتر کاربر.
2. computer-use روی ویندوز: ترمینال/IDE فقط «click» هستند (تایپ ممنوع) → اسکریپت `.bat` + `.ps1` در پوشه وصل‌شده بنویس، کاربر دوبار کلیک کند.
3. `device_bash` در این نشست‌ها در دسترس نبود؛ فایل‌ها با `device_commit_files` (حداکثر ۵۰ فایل در هر فراخوانی) منتقل شدند.
4. PowerShell 5: فایل `.ps1` فقط ASCII (فارسی/em-dash پارس را خراب می‌کند)؛ پایان خط CRLF؛ JSON را با `[IO.File]::WriteAllText(..., UTF8Encoding($false))` بنویس.
5. ویندوز: `python` ممکن است میان‌بر Microsoft Store (`WindowsApps`) باشد → نادیده بگیر و با winget نصب کن (`Python.Python.3.12 --scope user`).
6. pip روی اینترنت کند: `--timeout 180 --retries 10` و تا ۳ تلاش.
7. MCP خراب در `claude_desktop_config.json` ثبت نکن؛ فقط اگر exe وجود دارد. همیشه بکاپ بگیر.
8. هیچ secret (کلید API پنل پیامک، رمز) در فایل‌های handoff یا گیت‌هاب ننویس.
