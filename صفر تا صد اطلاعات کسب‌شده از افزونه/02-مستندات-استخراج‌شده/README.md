# ARIAGH.BECHARKHOON — افزونه بچرخون

گردونه شانس حرفه‌ای وردپرس و ووکامرس. نسخه ۱.۸.۰ — PHP 7.4+ ، وردپرس 5.8+ ، ووکامرس 6+ (اختیاری).

## شروع سریع

1. نصب zip و فعال‌سازی → خودکار به صفحه «گردونه‌ها» می‌روید.
2. «گردونه جدید» → یکی از ۱۲ الگو (خوش‌آمد، هدیه اولین خرید، خرید بالای ۲ میلیون، هر ۵۰۰ هزار تومان، جلوگیری از خروج، VIP، یلدا، نوروز…).
3. در ویرایشگر: جوایز و احتمال‌ها، «چه کسی و چند بار»، ظاهر (۳۶ تم)، پاپ‌آپ، فرم، تریگرها، کوپن، پیام‌ها، اعلان‌ها، زمان‌بندی. پیش‌نمایش زنده کنار صفحه است و «چرخش آزمایشی» ثبت نمی‌شود.
4. «پیامک و اعلان» → انتخاب پنل (۲۶ گزینه + اتصال دستی)، وارد کردن کلیدها، «ارسال پیامک تست».
5. برای «هرکسی اولین سفارش را ثبت کرد بچرخاند» یا «خرید بالای ۲ میلیون = یک شانس»: «قوانین شانس» → افزودن قانون → در گردونه، تب «چه کسی و چند بار» حالت «فقط با شانس کسب‌شده» یا «ترکیبی».

## شورت‌کدها

| شورت‌کد | کار |
|---|---|
| `[becharkhoon id="1"]` | گردونه داخل صفحه |
| `[becharkhoon_button id="1" text="بچرخون"]` | دکمه باز کردن پاپ‌آپ |
| `[becharkhoon_spins id="1"]` | تعداد شانس کاربر |
| `[becharkhoon_my_prizes]` | جوایز من |
| `[becharkhoon_winners id="1" count="10"]` | آخرین برندگان |
| `[becharkhoon_referral]` | لینک دعوت |

همچنین: بلاک گوتنبرگ «گردونه شانس»، ویجت المنتور، لینک `?bch_open=1` یا `#bch-open-1`، و `window.Becharkhoon.open(1)`.
