# ۰۵ — قوانین طراحی، گرافیک و فونت (درس‌نامهٔ جلسهٔ قبل + قانون ژاکت)

> این فایل، **حافظهٔ درایوگوگل** است: قوانین ۹ و ۱۰ پوشهٔ «کیت طراحی ژاکت» + اسکیل ساخت عکس + درس‌های پروژهٔ نوشتار.
> برای این محصول (بچرخون) همهٔ قوانین بازجذب می‌شوند، **فقط پالت رنگ تغییر می‌کند** (پالت این محصول سبز/نعنایی/طلایی است، از پرامپت کاربر).

---

## ۱. ۷ قانون طلایی ژاکت (تکرار نشدنی)

1. هیچ عدد نسخه و کلمهٔ «نسخه» در کاور، آیکون، اینفوگرافیک، دمو، اسکرین‌شات یا راهنما. نسخه فقط در فرم ثبت + هدر `Version:`.
2. اسکرین‌شات‌ها فقط از **نسخهٔ فارسی**؛ هر تصویر زیرنویس دارد.
3. صفر لینک بیرونی در توضیحات، `Help.pdf` و `Documentation.html` — حتی لینک سایت خودت.
4. صفر صفحه/فرم لایسنس در دمو (بند ۷).
5. ترتیب توضیحات: **معرفی (≥۲۰۰ کلمه / ۸۰۰ کاراکتر) → اینفوگرافیک → ویژگی‌ها → چنج‌لاگ**.
6. گوشهٔ **چپ-بالای** کارت ۴۰۰×۴۰۰ خالی بماند (نشان «بروزرسانی خودکار» ژاکت آنجا می‌نشیند).
7. ساختار بسته: `1- Plugin/` + `2- Addons/` + `3- Documentation/` + `Help.pdf` (عدد + خط تیره + **فاصله**).

## ۳. اسکیل ساخت گرافیک (اعداد دقیق، از پروژهٔ قبلی)

**بوم اینفوگرافیک:** عرض ثابت **۱۲۴۰px** · فاصلهٔ کناری ۴۰px در رندر ۱۳۲۰ (بعد کراپ) · شعاع بلوک ۲۸–۴۴px · پدینگ ۲۸–۳۸px.

**کف اندازهٔ فونت (QC ژاکت):** روی بوم ۹۰۰–۱۰۰۰px کف است؛ چون روی ۱۲۴۰ می‌سازیم **یک پله بالاتر** می‌گیریم:

| عنصر | کف ژاکت | مقدار روی ۱۲۴۰ |
|---|---|---|
| متن بدنه / توضیح کارت | ۱۷.۵–۱۹.۵ | ۱۷ (بدنه) · ۱۶.۵ (آیتم لیست/پیل) |
| زیرتیتر و توضیح بخش | ۲۰–۲۲ | ۱۹ |
| تیتر کارت / ماژول | ۲۲–۲۵ | ۲۱ (کارت) · ۲۹ (باند) |
| H2 بخش‌ها | ۳۴–۴۴ | ۴۰–۴۱ |
| H1 هیرو | ۵۶–۷۶ | ۵۶ |
| بج/چیپ/لیبل | ۱۴.۵–۱۶ | ۱۶.۵ (پیل) · ۱۵ (ایبرو) · ۱۴ (small) |
| خط ارتفاع | ۱.۷۵–۱.۸۵ | `line-height:1.85` |

**قاعدهٔ نمایش ۷۰۰px:** همه‌چیز ×۰٫۵۶۵ ⇒ **زیر ۸px نرو**. **قاعدهٔ تغییر عرض:** همهٔ اعداد × `1240 / عرض_جدید`.

**تکه‌های گالری:** ۱۲ تکه · ۱۲۴۰×۸۶۹ · JPEG q92 (~۱۵۰KB) · هر تکه یک بلوک کامل، برش در فاصلهٔ بین بلوک‌ها.

## ۴. روش رندر (سه مسیر تست‌شده)

- **Playwright ۱×:** viewport 1320×1100 → `scrollHeight` → `set_viewport_size` به همان ارتفاع → screenshot → کراپ ۴۰px هر طرف.
- **Playwright ۲× روی بوم بلند:** DPR=2 روی ارتفاع ۱۰٬۰۰۰px **شکست می‌خورد** (`Unable to capture screenshot`). راه: تکه‌های پیوسته با `STEP ≤ ارتفاع viewport` و گرفتن آفست واقعی `scrollY` (نه `y`)؛ یا `page.screenshot(clip=…)`.
- **مرورگر خود کاربر:** `F12` → `Ctrl+Shift+P` → *Capture full size screenshot* (یا `Ctrl+P` → Save as PDF با عرض ۱۲۴۰ و Background graphics روشن).
- **نسخهٔ تک‌فایلی HTML:** فونت و تصاویر base64 + پنل شناور دانلود (PNG 1240 / PNG 2480 / چاپ) + دکمهٔ «باز کردن در پنجرهٔ جدید» (در iframe پیش‌نمایش، دانلود بلاک می‌شود).

## ۸. پرامپت آرت سه‌بعدی (قالب)

```
3D render, Pixar-style friendly [character/object], [کار/حالت], soft studio lighting,
warm rim light, high detail, centered, full body visible, isolated on pure #00FF00
chroma-key background, no ground shadow, no white halo, no text, 1:1
```
- برش با آستانهٔ کانال G، پاک‌سازی هاله، خروجی WebP q85.
- هر آرت حداکثر **۲ بار** در یک محصول و **هرگز دو آرت کنار هم** در یک بلوک.
- برای شیشه: `teal_safe` و هرگز `mix-blend-mode: multiply`.

## ۹. درس‌های ریز اما پرهزینه

- فاصلهٔ رقم و کلمه در Peyda: فقط `word-spacing:.16em` روی پیل (bdi/&nbsp;/ZWNJ جواب نداد).
- نویز JPEG: q92 و ابعاد دقیقاً برابر بوم؛ اختلاف میانگین < ۲.
- اسکرول افقی از honeypot با `left:-9999px` ⇒ از `clip-path: inset(50%)` استفاده کن (درس محصول).
- لوگوی شریک (ژاکت) در فوتر تصویر: وسط‌چین، در **چیپ سفید** (خطوط لوگو خاکستری تیره است و روی نارنجی محو می‌شود)، بدون متن کنارش.
