# ۰۶ — اسکیل پیش‌نمایش (cPanel) و ساختار استانداردش

مرجع تجربی: پیش‌نمایش نوشتار (`neveshtar-preview`، ۸۰ فایل، ۳.۷MB) که روی cPanel آپلود و تست شد.
این فایل «قالب» پیش‌نمایش بچرخون است — همان ساختار، با محتوا و پالت بچرخون.

---

## ۱. ساختار پوشهٔ نهایی (قابل آپلود مستقیم در `public_html`)

```
becharkhoon-preview/
├── index.html                ← صفحهٔ معرفی (لندینگ) فارسی، RTL
├── site.css                  ← همهٔ استایل لندینگ (بدون فریم‌ورک)
├── .htaccess                 ← UTF-8 + DirectoryIndex + -Indexes + gzip + cache
├── assets/
│   ├── fonts/                ← فونت‌های محلی + css فونت
│   │   ├── fonts.css         ← @font-face با مسیر محلی
│   │   ├── Morabba-Black.ttf
│   │   ├── Peyda-Medium.ttf / Peyda-Bold.ttf / Peyda-Black.ttf
│   │   └── becharkhoon-ui.woff2  (نسخهٔ تک‌فایلی مشتق از فونت افزونه)
│   ├── img/                  ← icon-80.png، logo.svg، logo-white.svg، mark.svg، menu-icon.svg
│   ├── shots/                ← ۱۲ اسکرین‌شات پنل (webp) با نام صفحه‌ها
│   └── art/                  ← آرت سه‌بعدی (webp، شفاف)
└── demo/
    ├── index.html            ← دموی زندهٔ پنل SPA (بدون بک‌اند، با mock)
    ├── demo.css
    ├── views-bundle.js       ← DOM واقعی همهٔ صفحات پنل
    ├── mock-ajax.js          ← پاسخ‌های ساختگی endpointهای REST
    └── vendor/               ← jquery / jquery-ui محلی (نه CDN)
```

**قواعد سختِ cPanel (از تجربهٔ نوشتار):**
1. **صفر درخواست بیرونی** — همهٔ فونت/JS/CSS/تصویر محلی. هیچ `https://cdn...` یا `fonts.googleapis.com`.
2. مسیرها **نسبی** (`./assets/...`) تا در زیرپوشه (`/becharkhoon/`) هم کار کند.
3. `.htaccess` با `AddDefaultCharset UTF-8` (وگرنه فارسی خراب می‌شود)، `Options -Indexes`.
4. یک **پوشهٔ ریشهٔ واحد** در zip (`becharkhoon-preview/`) تا کاربر فقط آن را در `public_html` بریزد.
5. حجم کل زیر ~۸MB (فشرده) — تصاویر WebP q85–90.
6. فایل `demo/index.html` باید بدون PHP و بدون دیتابیس کار کند (هاست ارزان هم جواب بدهد).
7. لینک دمو از لندینگ به `./demo/` نسبی باشد، نه دامنهٔ کامل.

## ۳. دموی زندهٔ پنل (بدون بک‌اند)

پنل بچرخون یک SPA است با ۱۲ صفحه:
`dashboard · wheels · rules · spins · leads · credits · campaigns · reports · sms · settings · tools · guide`

برای دمو:
- `views-bundle.js` = DOM واقعی هر ۱۲ صفحه (استخراج از `assets/admin/*.js` و مارک‌آپ SPA).
- `mock-ajax.js` = پاسخ ساختگی برای endpointهای REST (`becharkhoon/v1/...`) با داده‌های نمونهٔ فارسی.
- ناوبری با hash (`#/wheels`) و بدون reload.
- **بدون صفحه/فرم لایسنس** (این افزونه لایسنس ندارد ✅).
- برچسب فارسی کوچک «دمو — داده‌های نمونه» مجاز است، اما هیچ نسخه/لینک بیرونی نه.

## ۴. رندر گردونه در پیش‌نمایش

گردونه باید **واقعی** باشد نه عکس: SVG با ۸ بخش، رینگ لامپ‌دار، هاب، پوینتر، و انیمیشن چرخش CSS.
الگوریتم مسیر بخش: `M cx,cy L x1,y1 A r,r 0 0,1 x2,y2 Z` با زاویهٔ هر بخش `360/n`.
برای تطابق با افزونه: رنگ‌ها از `themes-36.json`، `rim_style`, `center_style`, `pointer_style`, `win_effect` همان مقادیر مجاز (`enums-schema.json`).

## ۵. اسکرین‌شات‌های دمو — چطور گرفته می‌شوند

- viewport **۱۴۴۰×۹۸۰**، DPR=2، JPEG q90 (یا WebP q90 برای لندینگ).
- مخفی‌کردن نوار ادمین و نوتیس‌ها با یک `<style>` تزریقی.
- آدرس باید `localhost` باشد نه `127.0.0.1` (وگرنه کوکی نشست ست نمی‌شود).
- لاگین با `fill` + `Enter` مطمئن‌تر از کلیک دکمه.
- بعد از هر اسکرین‌شات، بررسی وجود `Fatal error|Warning:|Notice:` و **صفر بودن** آن.
- نام‌گذاری: `01-dashboard.webp` … `12-guide.webp` (دورقمی، اسلاگ انگلیسی).

## ۶. تست پیش از تحویل پیش‌نمایش

```

[ ] صفر درخواست بیرونی (Network tab: همه Same-origin)
[ ] فونت‌ها لود می‌شوند (بدون fallback سیستم)
[ ] فارسی و RTL درست، بدون کاراکتر شکسته
[ ] موبایل ۳۹۰px و تبلت ۷۶۸px بدون اسکرول افقی
[ ] همهٔ لینک‌های داخلی ۲۰۰ (بدون ۴۰۴)
[ ] حجم صفحهٔ اول < ۱.۵MB
[ ] بدون خطای کنسول
```
